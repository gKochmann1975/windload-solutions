# CLAUDE.md - Project Context for AI Assistants

## Project Structure Overview

This workspace is part of a multi-site architecture for Wind Load Solutions:

| Folder | Domain | Purpose |
|--------|--------|---------|
| `windload-solutions-parent` (this folder) | [windload.solutions](https://windload.solutions) | Parent/educational website, directs users to windloadcalc.com |
| `windload-solutions` | [windloadcalc.com](https://windloadcalc.com) | Main services & software site (wind load calculators, purchases, services) |
| `windload-co` | [windload.co](https://windload.co) | Marketing pages that funnel users to windloadcalc.com |

## Site Relationships

- **windload.solutions** - Educational content and parent brand presence
- **windloadcalc.com** - Primary conversion site for software and services
- **windload.co** - Marketing/landing pages driving traffic to windloadcalc.com
